# Editing scientific work in this project

Use the procedure in `docs/editing-protocol.md` when asked to edit a scientific passage. Work inside `private/` for authors' texts. Before editing, name the audience, research question, purpose and source version. Freeze the original, distinguish observations from interpretations, and ask for missing evidence only when that affects the statement. Use the source language and the requested target language. Give the reader a complete passage they can read without opening a checklist.

Preserve claim scope, attribution, significant digits, units, qualifications and citations. Keep explanatory analogies clearly identified, record unresolved interpretations for the author, and identify AI editorial assistance in the working record. Run the local checks. Only a named human can own a scientific judgment or report a completed reader assessment. Keep private packets, receipts and manuscripts out of Git by default.
