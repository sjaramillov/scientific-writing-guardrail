# Related work and scope of the comparison

Reviewed 26 November 2026. We examined the authors' documentation, release descriptions, papers and artifact records linked below. These are documented capabilities. This review did not benchmark the tools or test whether one improves readers' understanding. An undocumented feature is treated as unknown.

| Project or study | What the source establishes | What it contributes to interpreting this release |
| --- | --- | --- |
| Writing Guard | The authors describe local deterministic checks on quantities, citations, negation, causal strength and scope, Word safeguards and English and Chinese prose rules. The skill can also rely on its host model for editorial judgment. It is licensed under MIT. | A close precedent for protecting expressions during edits. Our example pairs each claim and its declared expressions with complete English and Spanish passages. [Writing Guard](https://github.com/xmutfyh/writing-guard-skill) |
| manuscript-guard 0.2.506 | The release describes 17 deterministic offline gates, a frozen analysis plan, numerical claims bound to results or quoted sources, human decisions and Word/PDF output. | Binding a number to its evidence is an important comparison. [Version 0.2.506](https://pypi.org/project/manuscript-guard/0.2.506/) |
| Scientific Reasoning Auditor 0.11.0 | The release documents a claim–evidence graph, separate hashes for the manuscript and extracted text, reviews linked to source material and Spanish screening rules. Local analysis and optional external-model modes have different data flows. | This is prior work for source provenance and multilingual scrutiny. Screening a Spanish manuscript and comparing two edited versions of one claim are separate tasks. [Version 0.11.0](https://pypi.org/project/scientific-reasoning-auditor/0.11.0/) |
| sciwrite-lint | The v2 paper describes checks for reference identity, metadata, retractions and support for a citation. The architecture combines local text processing with external bibliographic services. | Checking whether a citation supports a claim requires more evidence than locating a source quote. Our offline receipt leaves that judgment open. [Samsonau, §6](https://arxiv.org/html/2604.08501v2) |
| ai-writing-guardrails | Coastlight's Claude skill includes staged review, counter-search, decision records and procedures for checking references and preserving the author's language. The repository includes supporting scripts. | A precedent for documenting editorial judgment and author responsibility in an assisted workflow. [Coastlight](https://github.com/coastlight-ai/ai-writing-guardrails) |
| Academic Writing Filter | Simon Rudkin's framework defines a claim-preservation contract, allowed and excluded inferences, terminology constraints and thirteen rules for revision. The author offers the dated specification in Markdown. The paper leaves evaluation of effectiveness to future work. | The editor should define which inferences the source permits before revising prose. Protecting the words still leaves the scientific meaning to review. [Paper](https://arxiv.org/html/2610.33001v1) · [Author's artifact page](https://sites.google.com/view/simonrudkin/ai) |
| Auditable AI-Assisted Research Writing | Zhou and Yu describe hash-bound provenance, an index of claims and evidence, recorded refusals and controls on releasing sensitive relational information. The paper announced an artifact. The following day the authors deposited the audit package, version DOI **10.5281/zenodo.21905684**, on 12 August 2026. | Direct precedent for keeping internal evidence while distributing a separately defined public output. Their disclosure controls address sensitive relationships. Evaluating whether a translated number retains its referent is a different scientific check. [Paper](https://arxiv.org/html/2608.10858v1) · [Versioned artifact](https://doi.org/10.5281/zenodo.21905684) |
| Scriptorium | The project includes editing skills, shared manuscript state and documented reports on changes to claims, statistics, citations and terminology. | Both approaches invite review of explicit invariants. Translation quality assurance has its own history. Okapi CheckMate checks source and target segments against terminology and configurable patterns. XLIFF already defines aligned translation units and notes. We credit that work when describing bilingual alignment. ## What an editor can reproduce in 0.1.0

An editor can freeze one UTF-8 source, declare a claim map, supply one English and one Spanish segment per claim, and check literal expressions offline. The external notes expose a small set of fields chosen for a reader. The biodiversity exercise includes both a change this check detects and a change in meaning that requires a reader to catch. The source, both editions and the test are available together. [Worked example](../examples/biodiversity/README.md)
